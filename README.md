# Balachandar P — Portfolio

Animated, responsive CV portfolio for **Balachandar P**, focused on marketing automation, B2B/B2C campaign operations, production services leadership and global client delivery.

## Highlights
- Lightweight single-page implementation with no framework dependency
- Responsive and accessible layout
- Intersection-based reveal animations
- Canvas ambient particle field
- Magnetic CTA and 3D tilt interactions
- Reduced-motion support
- GitHub Pages deployment workflow

## Run locally
Open `index.html` directly, or serve the repository with any static HTTP server.

## Deploy
The included GitHub Actions workflow deploys `main` to GitHub Pages. In repository **Settings → Pages**, set **Source** to **GitHub Actions** if it is not already enabled.
